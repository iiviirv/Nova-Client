# The Aether core's entry points, kept in the app's dynamic export table.
#
# dart:ffi resolves these with dlsym at run time. The App Store build strips
# the executable, and a stripped Runner exported exactly one symbol
# (__mh_execute_header), so every lookup failed with "symbol not found" while
# the same code worked from a local flutter run, which does not strip. That
# shipped to TestFlight as build 148.
#
# An exported_symbols_list on an executable makes the export table exactly this
# set. That is safe here: the shipped binary exported nothing but the header
# anyway, so nothing was relying on the rest.
_aether_version
_aether_string_free
_aether_job_poll
_aether_job_cancel
_aether_identity_open
_aether_scan_start
_aether_verify_start
_aether_tunnel_start
